# MyTax Appointment Guide

Step-by-step guide for clients of YK Corporate Consultants Sdn Bhd:

1. Register the director role (Pengarah Syarikat) in MyTax
2. Appoint YKCC as tax agent in MyTax

Live page: https://ewong-max.github.io/mytax-appointment-guide/

Add `?agent=NAME` to the URL to fill in the tax agent name.
